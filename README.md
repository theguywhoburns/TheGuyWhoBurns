## My Projects

### Blowtorch
A declarative spiking neural network (SNN) library for PyTorch research. Neurons are described by plain nested classes, and everything else (parameter creation, constraints, resets, hidden state, and sequence scans) is handled automatically. No custom CUDA kernels; the speed comes entirely from init level logic and `torch.compile` over pure Python math(beats norse and snnTorch both in eager and compiled mode)
[theguywhoburns/blowtorch](https://github.com/theguywhoburns/blowtorch)
